# Demo projektas (agento smėlio dėžė)

Šis katalogas nukopijuojamas į `work/projektas` ir yra vieta, kur Cline realiai dirba:
skaito failus, rašo, leidžia komandas. Niekas iš čia nepatenka į tavo tikrą kodą,
kol pats nepasidarysi `git clone` į `work/`.

Patikrinimas:

```bash
node check.js
```

Tikėtina išvestis: `OK: visi failai vietoje (3 receptai)`.
